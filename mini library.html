Mini Library System

Python Project by Om Tambat

Introduction

The Mini Library System is a Python project that helps organize library information and book records. It uses CSV file handling to save and read data.

Project Features

1. Add Multiple Libraries

Create records for different libraries.

2. Add Multiple Books

Store details of books in library records.

3. Save Records

Use Python's CSV module to store information in a CSV file.

4. View Entries

Read the saved file and display its records.

Technologies Used

  • Python
  • CSV file handling
  • HTML
  • CSS
  • GitHub

What I Learned

I learned how to organize data, work with files, save records and build a simple Python application.
